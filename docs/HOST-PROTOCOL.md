# Host protocol

`$.global.SeamlessMaker.dispatch(payload)` receives a strict JSON string and returns a JSON string with `{ok:true,data:...}` or `{ok:false,error:"message"}`. It never evaluates request data as JavaScript. The CEP bridge serializes host calls to avoid overlapping preview transactions. Before dispatch, it checks the host version and, if missing/outdated, loads `host/main.jsx` using CEP's absolute extension folder. Initialization errors return `{ok:false,errorEncoded:"URI-encoded message"}` even when the legacy JSON module has not loaded yet. Normal calls reuse the namespace and source session.

Actions:

- `inspect`: returns `{artboard:{index,rect,width,height},version}` for the current document.
- `capture`: validates exactly one selected SymbolItem, retains its live reference, and returns `{sourceToken,name,artboard}`. Invalidates the previous source/session.
- `prepare`: accepts `{sourceToken,settings,refresh?}`; returns `{previewToken,settings,artboard,image,count,exceeded,warning}`. `refresh:true` forces a new PNG. Image contains `{width,height,padding,uri}` in points plus a file URI. Footprint is measured **after** Illustrator applies Scale/Rotation, so effects, strokes and pre-existing transforms use host bounds rather than an assumed rotated rectangle.
- `create`: accepts `{sourceToken,previewToken,settings}`. Returns `{count,width,height,name}`. Requires the latest prepared snapshot and matching source/document/artboard/settings. The host computes all positions independently using the shared module, never trusts client-supplied positions/counts, and rolls back its own output on failure.
- `release`: removes session-owned PNG files and clears the source reference.

Settings: `{sizeMode:"artboard"|"custom",width,height,columns,rows,mode:"all"|"vertical",layout:"grid"|"stagger"|"lattice",scale,rotation,offsetX,offsetY}`. All measurements are in points; Scale is percent and Rotation is additional Illustrator degrees. Positive offsets mean right/down. Active-artboard width/height are resolved by the host. Width/height and offsets sent by the UI are converted from display units before dispatch.

Since 1.1.2, transform/offset controls are absent from the panel; it sends `scale:100,rotation:0,offsetX:0,offsetY:0`. These protocol fields remain supported for host scripting and regression checks. Preview zoom/pan is client-only state and is never sent to the host or included in the Create snapshot.

For `layout:"lattice"`, both modes require integer `columnShift` (UI: Column Tilt). All Sides also requires integer `rowShift` (Row Tilt) and positive integer `rowCycles` (Rotary Unit). Top–Bottom instead requires `horizontalX` / `horizontalY` in points; X must be nonzero. `columns` remains a valid positive integer in the payload but does not determine Top–Bottom lattice spacing. Tilt counts have magnitude at most 10,000. See [lattice formulas](LATTICE.md).

Coordinates in the shared module are tile-local, positive Y down; the host translates to Illustrator coordinates using `[artboardLeft + x, artboardTop - y]`. Each target position is the center of the transformed SymbolItem's visible bounds. Document.imageCapture captures the measured bounds plus up to 1 pt transparent padding, excluded from the geometric footprint. Resolution is between 72 and 144 PPI, targeting 2048 pixels when the 72-PPI minimum permits. Large previews can exceed that pixel target. The pad shrinks only when needed to fit the 16383-point legacy canvas limit.

Since 1.1.6, preview uses the current document. The host measures the union of existing artwork and artboards, duplicates the Symbol on a temporary layer, and moves the copy to an empty region outside that union. Original layer visibility and locks are never changed. The host redraws before beginning its capture and after removing the temporary layer; it never redraws while the copy exists. In 1.1.8+, the temporary preview layer is removed directly and `doc.saved` is restored explicitly without calling `app.undo()`, eliminating heap corruption (`0xc0000374`) and access violation (`0xc0000005`) crashes previously caused by undoing across deleted DOM pointers. If no isolated region is available within the canvas, preview returns an error instead of creating another document.

The repeat module returns `{points:[{x,y},...],count,exceeded,warning}`. Lattice points also contain zero-based `column` and `row` indices, and the plan includes `lattice:{horizontal,vertical,verticalMatch,horizontalMatch}`. `vectors(settings)` exposes this basis and seam compensation without allocating positions. Once a limit is crossed, `count` is a lower bound (not necessarily the full count), `points` is empty, and `exceeded` is true. This prevents an expensive allocation for enormous inputs. Nonfinite counts serialize to JSON null; the panel compares exact counts only for plans within the limit, and displays `> 10,000` for exceeded plans.

Since 1.1.10, occupied bounds use one native `doc.visibleBounds` read combined with artboard/source bounds; no pageItems collection is enumerated and no sampled bounds are trusted. Invalid/unavailable native bounds fail before creating temporary artwork. Every prepare invalidates the previous prepared token. Temporary-layer cleanup/restoration errors delete the partial PNG, keep the document dirty and mark the source session unusable for prepare/Create. The user must check/remove the temporary preview layer and recapture the source. No Undo/Redo calls are used.
